# Dark Star

A combined-arms shooter for the PlayStation Vita, from the Silent Nights Project. Offline, against bots.

**Release page:** https://division6.net/dark-star/ (from November 22, 2026)

## Download

Every build is a GitHub release tagged with its version, and every file carries the version in its
name, for example `DarkStar-v59.0.vpk`. Grab the newest one from [Releases](../../releases/latest).

## Install

1. You need a PS Vita running HENkaku/Enso or h-encore, with VitaShell.
2. Copy the VPK to the Vita (for example to `ux0:`, over USB or FTP in VitaShell), highlight it and press Cross.
3. Start Dark Star from the LiveArea. Installing over an older version keeps your save.

## Update feed

Each release carries a `latest.json` that lists its version, file, size and SHA-256. The newest
published one is always at:

```
https://github.com/spiritus5150/DarkStar/releases/latest/download/latest.json
```
